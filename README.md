# IKEA Escape Room

## About the project

As part of a school project, we designed and developed an interactive **escape room website set in an IKEA environment**. The concept combines IKEA's recognizable visual identity with puzzles, challenges and a playful user experience.

## Our process

Working as a team, we used our **UX knowledge and agile methods** throughout the project. We developed the concept, user flow, visual design and interactive elements before bringing the experience to life through code.

## What I learned

* UX and user-centered design
* Agile teamwork and collaboration
* Interaction and visual design
* Frontend development
* Turning a concept into an interactive web experience
